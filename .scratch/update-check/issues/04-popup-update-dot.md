# 04 — popup 小红点

**What to build:** 用户看到工具栏角标后的第一反应是点开 popup。有可用更新时，popup 顶部品牌栏出现一个小红点；点一下直接跳到设置页的关于分区更新面板，用户不必自己想到去设置里翻。

职责分明：**popup 负责告知，关于分区负责执行**。这里不放任何步骤说明或操作按钮——popup 的宽度塞不下，两个场景标签页的竖向空间也不该被占用。

**Blocked by:** 03（点击要落到已经建好的更新面板上，否则跳过去只有旧的关于分区）

**Status:** ready-for-agent

- [ ] 有可用更新时，popup 顶部品牌栏出现小红点；不成立时完全不占位、不留空白
- [ ] 小红点只放在场景无关的品牌栏，不侵入「直播实时」「视频字幕」两个标签页的内容区
- [ ] 点击后打开设置页并直接落在关于分区（不是设置页的默认分区）
- [ ] popup 打开时不自行发起更新检查——它只读状态机已有的结论
- [ ] 小红点的显隐由同一份可用更新状态驱动，与角标不会出现一个有一个没有的情况
- [ ] 视觉上不与既有的设置齿轮图标挤在一起或遮挡它
