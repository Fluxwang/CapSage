# 04 — 源语言可配置 + 翻译模型下载联动

**What to build:** 源语言不再写死西班牙语。popup 里的"源"下拉是真的可选，选什么语言，AssemblyAI 就按什么语言转写、本地翻译就从什么语言译出。换到一个没下载过本地模型的语言对时，设置页会重新出现该语言对的下载提示和进度，而不是只有一个固定的"西→中"下载按钮。

**Blocked by:** 01（转写/翻译核心）, 03（下载流程所在的设置页分区）

**Status:** resolved

- [x] 会话初始化接受源语言参数，AssemblyAI 连接参数与 Chrome Translator 的源语言都吃这个值，代码里不再有写死的 `"es"`
- [x] popup「直播实时」Tab 的"源"下拉可选并持久化；开始捕获后中途不可改（改动下次生效）
- [x] 目标语言锁死中文，UI 上不做选择器
- [x] 切到未下载过的语言对时，设置页出现该语言对的下载提示/进度；下载只能由页面上的按钮点击触发
- [x] 设置页"翻译模型"那一项的标题文案跟随当前语言对，不再写死"西→中"
- [x] `core/` 的会话初始化补一个"不同语言值透传不变"的测试用例（reducer 逻辑不因语言分叉）
- [x] 当前语言对的本地模型不可用时，给出明确提示而不是静默失败（ADR-0003 的能力检测要求）

## Answer

源语言通过 popup 选择并保存，随会话传给 AssemblyAI 和 Translator；目标固定为简体中文。设置页按当前语言对检查、下载并显示本地模型状态，核心测试覆盖语言值透传。
