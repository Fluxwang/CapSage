# 03 — 统一设置页（四个分区 + 关于）

**What to build:** 从任一个 Tab 点 ⚙ 打开的是同一个设置页，左侧四个分区：直播实时 / 视频字幕 / 叠加层外观 / 关于。AssemblyAI Key 和强调色各只填一次、两个场景共用，不再像合并前那样两个扩展各配一遍。

**Blocked by:** 01, 02（两个场景的设置字段都要存在，才谈得上合并成一份）

**Status:** resolved

页面结构与文案以仓库根的 `Popup 合并设计.dc.html` 为准，但注意 spec 的 "UI Design Reference" 一节列了几处设计稿已过时、要以 spec 为准的地方。

- [x] 一个 options 页、四个分区，与设计稿结构一致
- [x] AssemblyAI Key（含保存并校验、清除）与强调色都只有一份，改动对两个场景同时生效
- [x] 强调色应用于 popup/侧边栏/设置的按钮与高亮；**悬浮层本身始终白字黑底**，不跟随强调色
- [x] 「译文触发时机」（停顿 / 句子）从 01 迁移过来后**挪到中性位置**，不挂在"直播实时"分区下——它对两个场景都生效（ADR-0007）
- [x] 「直播实时」分区**没有**翻译引擎选择器（引擎选择属于视频字幕场景，见 05）
- [x] 「关于」页内容按设计稿：产品由来说明、三条数字事实、更新日志/反馈/隐私链接
- [x] 设置改动即时保存，无需"保存"按钮（设计稿右上角标注"修改即时保存"）

## Answer

已提供单一四分区设置页：共享 AssemblyAI Key、触发时机和强调色即时保存，视频专属 AI 配置独立放在视频分区；悬浮层保持固定黑底白字。
