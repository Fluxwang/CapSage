# 08 — 悬浮层通用化：视频字幕场景的「悬浮窗」开关

**What to build:** 侧边栏里打开"悬浮窗"，视频字幕就不只躺在列表里了——它会像直播实时场景那样，以双轨悬浮层的形式盖在视频画面上，跟着播放进度走。用的是同一个悬浮层组件，只是喂给它的数据换成了"已经攒好的带时间戳字幕数组 + 当前播放进度"。

**Blocked by:** 06（流式转写来源与播放进度采样层）, 07（开关所在的侧边栏子页）

**Status:** resolved

- [x] 悬浮层组件接受两种喂入方式：直播的**实时流式单位增量**，和视频字幕的**静态字幕数组 + 播放进度定位**
- [x] 侧边栏「悬浮窗」开关生效，原生 WebVTT 字幕和 AssemblyAI 流式转写两种来源都能正确渲染
- [x] 进度定位复用 06 的采样层，不新造一套
- [x] 悬浮层保持白字黑底，不跟随强调色（ADR 之外的设计约束，见 spec）
- [x] 拖动/双击复位/位置持久化等既有悬浮层行为在两个场景下都保持
- [x] 直播实时场景的悬浮层行为无回归——特别是流式喂入路径不能因为新增静态喂入而改变时序

## Answer

同一浮层现在既接收直播增量，也接收视频字幕数组和当前 cue 索引。视频侧边栏开关通过后台路由更新浮层，复用播放采样结果并保留黑底白字、拖动、双击复位和位置持久化行为。
